**SOLARIS BAY** is an offline, cinematic open-world driving and crime game set across four connected districts. Drift the Sunset Coast, outrun SBPD through neon downtown, fight through the harbor, then tune your car on Coral Island. The game uses local Three.js assets, procedural scenery, and synthesized audio without runtime network requests.

## Controls

- **WASD / arrow keys**: drive and steer
- **Space**: handbrake drift; **Shift**: nitro
- **E**: enter or exit the car, interact with a mission, or open Pay N Tune
- **M**: city map; **Escape**: pause; **R**: change weather; **N**: radio
- On foot, click to fire; **1–5** select weapons; hold **Tab** or **Q** for the weapon wheel

## Districts and missions

Explore Sunset Coast, Neon Downtown, Harbor Docks, and Coral Island through eight story contracts. Earn cash and reputation, customize the SOLARIS GT, take on SBPD pursuits, and roam freely between missions. Local browser storage keeps your progress between visits.

## Run it

From the repository root, run `node serve.ts`, then open `http://localhost:8080`.
